🍕 Compare Price Feature - Visual Demo

📋 How It Works

Compare Price (Prezzo Prima): The original price shown with a strikethrough

Current Price (Prezzo Attuale): The sale/discounted price shown in bold orange

Admin Panel: Simply enter both prices when creating/editing a product

Display Logic: If compare_price > 0, it shows with strikethrough. Otherwise, only current price is shown.

🎯 Come Usare nel Pannello Admin

Passo 1: Vai su Admin Panel → Products

Passo 2: Crea o modifica un prodotto

Passo 3: Inserisci il prezzo corrente nel campo "Price (€)"

Passo 4: Inserisci il prezzo originale nel campo "Compare Price (€)"

Passo 5: Salva il prodotto

💡 Suggerimento: Lascia il campo "Compare Price" vuoto (o a 0) per i prodotti senza sconto. Il prezzo barrato apparirà solo quando compare_price > 0.
